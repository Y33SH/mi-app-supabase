# YESH PROYECTOOUU!

Proyecto básico realizado con Node.js y Supabase.

## Descripción

Este proyecto permite conectarse a una base de datos de Supabase desde JavaScript utilizando la librería `@supabase/supabase-js`.

El programa consulta los registros almacenados en la tabla `Estudiantes` y muestra los datos en la terminal, utilizado como base para el proyecto del laboratorio.

## Tecnologías utilizadas

- Node.js
- JavaScript
- Supabase
- Git
- GitHub
- Visual Studio Code

## Instalación

Instalar las dependencias con:

```bash
npm install
```

## Ejecución

Para ejecutar el proyecto:

```bash
node index.js
```
